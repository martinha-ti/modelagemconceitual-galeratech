# modelagemconceitual-galeratech
Modelagem conceitual de banco de dados para gestão de Pet Shop, utilizando MER. Contempla as entidades Tutor, Pet, Loja, Funcionário, Serviço, Atendimento e Item de Atendimento, detalhando atributos, chaves primárias e estrangeiras, relacionamentos e cardinalidades para representar as regras de negócio do sistema.
